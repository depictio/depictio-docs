# Advanced visualizations: screenshots

Every entry of [`docs/features/advanced-visualizations.md`](../../../features/advanced-visualizations.md)
shows one pair, `<viz_kind>_light.webp#only-light` and `<viz_kind>_dark.webp#only-dark`, where
`<viz_kind>` is the value of `viz_kind` (`volcano`, `molecule_3d`, ...). The volcano tile with each
`controls_placement` adds `controls_{popover,rail,header}_{light,dark}.webp`, and the floating 3D
panel `floating_structure_{light,dark}.webp`.

## How to regenerate

From the `advanced_viz_showcase` project of the release, served by a throwaway `depictio local up`
instance with its own `DEPICTIO_LOCAL_HOME` (the showcase has to be added to its seed list), run
`dev/advanced_viz_docs_screenshots/capture_tiles.py` from the depictio repo. It opens each showcase
dashboard in light and dark with the onboarding tour marked as seen, clips the tile with 4 px of
padding at a 1780 px viewport, and writes PNGs. Convert them with `cwebp -q 82 -m 6`.

The residue-linking diagram in `../protein-tiles/` is generated by
`dev/diagrams/protein_residue_linking.py` in the depictio repo.
